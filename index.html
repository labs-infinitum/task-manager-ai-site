task-manager-ai

A personal, self-hosted assistant that keeps one person's task list in sync with their conversations.

task-manager-ai is a private tool built and run by Infinitum Labs for its operator's own use. It is not offered to the public and has no sign-up.

What it does

  • Every 15 minutes it checks the operator's own accounts (email, chat, GitHub and meeting notes) for new messages.
  • It works out what changed: new requests, decisions, deadlines and finished work.
  • It updates the operator's self-hosted task tracker, adding tasks, comments and links back to the source message, and writes a short digest.

Google account access

The operator connects their own Google accounts with read-only Gmail access (gmail.readonly). task-manager-ai never sends, deletes or changes email. See the privacy policy for exactly how that data is handled.

task-manager-ai's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
