Privacy Policy

Effective 28 September 2026 · updated 29 September 2026 (Google Meet files, Notion)

task-manager-ai (“the app”) is a personal, self-hosted tool operated by Infinitum Labs for the sole use of its operator. This policy explains what data the app accesses, how it is used, where it is stored and who it is shared with, including data received from Google APIs.

Who can use the app

Only the operator. The app has no public sign-up, and it only connects to Google accounts that belong to the operator and that the operator has explicitly authorized.

Google user data the app accesses

With the operator's consent, the app requests these scopes:

  • https://www.googleapis.com/auth/gmail.readonly: message headers (sender, recipients, subject, date), message bodies as plain text, attachment file names (not attachment contents), and Gmail labels, for example to skip spam, promotions and social mail.
  • https://www.googleapis.com/auth/drive.meet.readonly, only on accounts where the operator enables it: Google Drive files created by Google Meet, i.e. meeting transcripts and “Notes by Gemini” documents, read as plain text with their title, owner and creation time. No other Drive files are visible to the app.

The app cannot send, delete, modify or label email, and cannot create, change or delete Drive files. It never does.

Notion data

The operator may also connect Notion workspaces they belong to, either with a personal access token they create in that workspace (which can see what the operator can see) or through Notion's OAuth consent screen (which sees only the pages the operator shares). The app only reads from Notion: its Notion client refuses any request that would create, edit or delete content or comments. It reads pages, comments and property values to find mentions of the operator and changes to task databases, and stores them in the same way as the Google data described below.

How the data is used

Google user data is used only to provide the app's single feature to the operator: working out which messages and meeting action items need the operator's attention and keeping the operator's own task tracker up to date. Specifically, the app:

  • classifies new messages (for example: a request for the operator, a decision, a deadline, or no action needed);
  • creates or updates tasks and comments in the operator's self-hosted task tracker, with a link back to the original message;
  • writes a private digest for the operator.

Google user data is not used for advertising, is not sold, and is not used to build user profiles for any other purpose.

AI processing

To classify and summarize messages, the relevant message content is sent to Anthropic's Claude models, which act as a processor for the operator solely to produce the classifications, summaries and task updates described above. task-manager-ai does not use Google user data to develop, improve or train generalized or non-personalized AI or machine-learning models.

Where the data is stored

  • Message data is stored in a database on the operator's own server, with access restricted to the operator's account.
  • OAuth refresh tokens are stored on the same server in files readable only by the operator's account.
  • Tasks, comments and digests derived from messages are stored in the operator's self-hosted task tracker.

Sharing

Google user data is not shared with, transferred to or sold to anyone, except:

  • Anthropic, as described under “AI processing”, only to provide the feature to the operator;
  • where required by law.

No human other than the operator reads the data.

Retention and deletion

Data is kept on the operator's server until the operator deletes it. The operator can stop all access at any time by revoking the app at myaccount.google.com/permissions. After access is revoked, the app can no longer read any new email, and the stored data can be deleted on request.

Limited Use

task-manager-ai's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be published on this page with a new effective date.
